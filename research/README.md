# research/

Freeform research scratch. Not synced with Obsidian. Anything that
belongs to the permanent research memory must live in `obsidian/`.

Use this folder for:

- Quick throwaway notebooks.
- Local dataset exploration drafts.
- Sketches before promoting to a hypothesis note.

Do NOT put:

- Canonical hypotheses (go to `obsidian/02_Hypotheses/`).
- Backtest reports (go to `obsidian/04_Backtests/`).
- Rejected notes (go to `obsidian/05_Rejected/`).
- Lessons (go to `obsidian/07_Lessons/`).
