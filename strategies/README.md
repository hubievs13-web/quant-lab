# strategies/

QuantConnect-ready strategy code. One folder per hypothesis:

```
strategies/Hxxxx_<slug>/
  main.py         # paste into QuantConnect project 30774195
  README.md       # per-strategy readme
  diagnostics.md  # what to extract from the QC run
```

Rules:

- `main.py` is single-file and paste-ready. No imports outside Lean
  Python. The QuantConnect web IDE expects a single file.
- The first line of `main.py` MUST be a profile tag comment, for
  example `# PROFILE: A-Maker`.
- Fee, slippage, risk, and diagnostic plumbing are NOT to be
  reinvented per strategy. Copy the canonical implementations from
  `strategies/_lib/` and inline them into `main.py`. The inlined code
  must match `_lib` byte for byte except for class renaming.
- Pre-fee edge floor and friction depend on the declared execution
  tier; see `obsidian/01_Rules/02_Fee_Slippage_Model.md`. Tier T:
  pre-fee floor 0.30 percent, friction approximately 0.18 percent.
  Tier M: pre-fee floor 0.20 percent, friction approximately 0.08
  percent. The previous 0.10 percent figure is retired.
- Free parameters <= 3, declared as module-level UPPER_SNAKE_CASE
  constants near the top of `main.py`.
- No emoji, no promotional text, no profitability claims.
- Generated by Codex in engineer mode. Do not hand-edit to tune.

Local validation before paste-into-QC:

```
python scripts/lint_strategy.py strategies/Hxxxx_<slug>/main.py
```

The lint must exit 0. Paste the lint summary into the strategy
`README.md` under a section titled `## Lint` so the auditor can
verify it.

## strategies/_lib/

Canonical reference implementations. Not imported by `main.py`
(QuantConnect web IDE requires a single file). Used by the engineer
prompt as copy-paste source and by `scripts/lint_strategy.py` as the
canonical structure to validate against. See
`strategies/_lib/README.md`.
