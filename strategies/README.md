```
  README.md       # per-strategy readme
  diagnostics.md  # what to extract from the QC run
```

Rules:

- main.py is single-file and paste-ready. No imports outside Lean
  Python.
- Fees and slippage hard-coded to the v1 model (taker 0.04 percent per
  side, round-trip friction approximately 0.18 percent) unless
  README.md explicitly documents a deviation.
- Free parameters <= 3, declared as module-level constants at the top
  of main.py.
- No emoji, no promotional text, no profitability claims.
- Generated by Codex in engineer mode. Do not hand-edit to tune.
